# MUSCLE BUILD PRO MAX

اپلیکیشن وب واکنش‌گرا و قابل نصب (PWA) برای برنامه تمرینی فارسی.

## اجرا
- برای تست سریع، `index.html` را باز کنید؛ ممکن است برخی مرورگرها به‌دلیل محدودیت `fetch` فایل JSON را از `file://` بارگذاری نکنند.
- روش پیشنهادی: در پوشه پروژه اجرا کنید:
  `python -m http.server 8000`
  سپس `http://localhost:8000` را باز کنید.
- برای انتشار، تمام محتویات این پوشه را در ریشه یک مخزن GitHub قرار دهید و از Settings → Pages، شاخه `main` و پوشه `/root` را انتخاب کنید.
- پس از انتشار با HTTPS، اپ قابلیت نصب PWA و کش آفلاین دارد.

## فایل‌ها
- `index.html`: ساختار صفحه
- `styles.css`: طراحی واکنش‌گرا
- `app.js`: منطق برنامه، تب روزها، جست‌وجو، ثبت انجام حرکت و تایمر
- `workouts.json`: اطلاعات برنامه و نسخه تمرین‌ها
- `manifest.webmanifest`: مشخصات نصب اپ
- `sw.js`: سرویس‌ورکر و کش آفلاین
- `assets/`: آیکن و طرح‌های شماتیک آموزشی حرکات

## شخصی‌سازی
برای تغییر ست‌ها یا ترتیب حرکات، فایل `workouts.json` را ویرایش کنید.
برای تغییر رنگ‌ها، متغیرهای ابتدای `styles.css` را تغییر دهید.

## نکته درباره تصاویر
تصاویر این نسخه، طرح‌های شماتیک اختصاصی و ساده هستند، نه عکس واقعی یا ویدیوی تخصصی اجرای حرکت. برای نسخه انتشار حرفه‌ای، بهتر است آن‌ها را با تصاویر/ویدیوهای آموزشی معتبر و دارای مجوز جایگزین کنید.

## نکته ایمنی
این برنامه ابزار ثبت تمرین است و جایگزین نظر پزشک یا مربی واجد صلاحیت نیست. سابقه درد قفسه سینه یا تنگی نفس حین ورزش باید پیش از تمرین سنگین بررسی پزشکی شود.
